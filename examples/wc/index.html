Feature showcase

@anil-labs — Web Component

Every feature in one place. Use the same attributes from any framework or plain HTML.

Selection modes

Single date

Default mode. Click any day. Today is marked with a dot.

Range — hover preview

Click an anchor, then hover anywhere — see a lighter tentative range until you click the second date.

Multi-date

Click multiple dates to toggle. Saves all selections.

Custom display format

value (ISO): 2025-04-15

EU format input

format="dd/MM/yyyy". Both display and storage use this format.

Navigation

Header month/year dropdowns

Pass header-selectors. Jump to any month/year in a click.

Multi-month — 2 months side-by-side

months="2". The range selection band spans across months.

Preset shortcuts

presets="today,last7days,last30days,thisMonth,clear".

Today button only

Built-in default.

Visual options

Week numbers

ISO week numbers on the left. Pass week-numbers.

Highlighted dates (events / holidays)

Pass highlights="2026-12-25|#dc2626|Christmas, 2026-01-01|#16a34a|New Year". Colored dot under the number.

Dark theme + dense

theme="dark" density="dense".

RTL — Arabic locale

locale="ar-EG". Layout mirrors.

Time / DateTime

24-hour clock

with-time. Default 24-hour, minute step 1.

12-hour clock + AM/PM + seconds

with-time clock="12" seconds.

DateTime input — 15-minute step

Combines with-time with a 15-minute step. Format: HH:mm.

(none)

Calendar systems

Bikram Sambat — English transliteration

calendar="bikram-sambat" locale="en-US". Months: Baishakh, Jestha, …

Bikram Sambat — Nepali (Devanagari)

locale="ne-NP" renders month names + day digits in Devanagari.

Constraints

min / max bounds

Dates outside the range are dimmed and not clickable.

Disabled weekdays

disabled-weekdays="0,6" blocks Saturdays + Sundays.

Disabled specific dates

disabled-dates="2025-12-25, 2025-12-26".

Range length 3–7 days

min-range-days="3" max-range-days="7". After picking an anchor, cells outside the allowed window are disabled.
